# Методология отбора семантики NextGen

## Параметры

- Россия (`225`), все устройства, последние 30 дней.
- Основной пул: частотность от 500 после исключения посторонних смыслов.
- Резерв: 300–499 для тем с прямым соответствием услугам NextGen.
- Ниже 300: не отдельная статья первой волны.
- Общая частотность и диагностическая частотность в кавычках записываются раздельно.

## Проход исследования

1. Запустить Wordstat по четырём направлениям: аутрич, Telegram-рассылки, B2B-лидогенерация, ИИ для продаж.
2. Проверить варианты написания: ТГ/телеграм/телеграмм/Telegram, B2B/Б2Б, ИИ/AI.
3. Выгрузить до 200 фраз по каждому стартовому запросу.
4. Оценить смысл каждой подходящей формулировки: кто ищет, какую задачу решает, соответствует ли она услугам и возможен ли полезный материал.
5. Повторить Wordstat для выбранной фразы с минус-словами при загрязнённом спросе. Не вычитать частотности вручную.
6. Проверить первые 10 результатов Яндекса и определить формат: услуга, инструкция, сравнение или кейс.
7. Сгруппировать близкие запросы по одной потребности. Один кластер получает один канонический URL.
8. Связать материал только с подходящим кейсом после подтверждения спроса: запрос → задача → решение → кейс.

## Принятие решения

Каждый кластер получает один из статусов:

- `основной пул` — частотность от 500, релевантный смысл и понятная страница;
- `резерв` — 300–499 либо требуется дополнительная проверка выдачи;
- `объединить` — совпадает по намерению с уже выбранным кластером;
- `исключить` — нерелевантный смысл, брендовая выдача или недостаточный спрос.

Приоритет среди одобренных кластеров: близость к услуге, ясность бизнес-задачи, наличие подтверждающего кейса, затем частотность.

## Контроль качества

- Частотность не считать прогнозом трафика.
- Не суммировать пересекающиеся фразы до порога.
- Не приписывать узкой теме частотность широкого родительского запроса.
- Не создавать тему только потому, что под неё есть кейс.
- Не запускать отраслевую статью, пока нет подтверждённого отраслевого спроса.
- Остановить сбор после двух последовательных проходов без новых релевантных кластеров и показать фактическое количество тем.
