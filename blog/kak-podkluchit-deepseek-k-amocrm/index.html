Как подключить DeepSeek к amoCRM через n8n: пошаговая инструкция по настройке ИИ-агента

DeepSeek совершил революцию, предоставив мощь передовых LLM по цене в 10 раз ниже американских аналогов. Разбираем, как связать DeepSeek с amoCRM через no-code платформу n8n.

NextGen AI19 сентября 20269 минут

Короткий ответ

Подключение DeepSeek к amoCRM через n8n состоит из 4 шагов: 1) получение API-ключа DeepSeek, 2) настройка вебхука на входящее сообщение в amoCRM, 3) создание ноды в n8n с промптом и системными инструкциями для LLM, 4) отправка сгенерированного ответа обратно в чат и обновление кастомных полей сделки. Решение работает автономно 24/7 с нулевой абонентской платой за софт.

Пошаговый сценарий настройки связки n8n + DeepSeek

  1. Webhook Node: принимает входящее событие от amoCRM (новое входящее сообщение в неразобранном или сделке).
  2. Data Transform Node: извлекает текст сообщения клиента, имя и ID контакта.
  3. HTTP Request Node (DeepSeek API): отправляет POST-запрос на https://api.deepseek.com/chat/completions с системным промптом компании и историей последних 5 сообщений.
  4. amoCRM API Node: отправляет ответ нейросети в чат клиенту и переводит сделку на следующий этап воронки.

Пример идеального системного промпта для DeepSeek

«Ты — ведущий менеджер по продажам компании NextGen AI. Твоя цель — вежливо поздороваться, выявить потребность клиента по 3 вопросам и предложить созвон в Zoom. Запрещено: называть цены без уточнения объема, выдумывать несуществующие скидки. Если вопрос выходит за рамки базы знаний, позови человека».

Почему n8n лучше облачных Make и Zapier

n8n можно развернуть на собственном VPS-сервере в РФ за 500 ₽/мес. Вы не зависите от зарубежных блокировок, не платите за каждую операцию и полностью соответствуете 152-ФЗ о хранении данных в России.

Частые вопросы по теме

Сколько стоит 1 000 ответов через DeepSeek API?

Около 15–30 рублей в зависимости от длины контекста, что делает решение практически бесплатным для бизнеса.

Что делать, если DeepSeek зависнет или не ответит?

В n8n настраивается ветка Error Trigger: если API не отвечает в течение 5 секунд, система автоматически ставит задачу дежурному менеджеру-человеку.
